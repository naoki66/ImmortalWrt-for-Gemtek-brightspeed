switch-vlan 重设计预览 — V3 布局 + 描述列

对 /cgi-bin/luci/admin/network/switch-vlan 的 DSA bridge-vlan 视图的视觉与交互原型。回退到 V3：每格一个 3 态下拉（非成员 / 标记 / 不标记）+ 内联 PVID 按钮；并新增每个 VLAN 的描述列，序列化时在 config bridge-vlan 之后写入 # 注释。

双轴模型（重要）：
轴 1 · 成员方式（按 端口 × VLAN）→ 非成员 / 标记(tag) / 不标记(untag)，描述端口"如何处理"这个 VLAN。
轴 2 · 主 VLAN / PVID（按 端口，全局唯一）→ 该端口的入站缺省 VLAN 身份。仅可与 不标记 共存（→ :u*，即裸 lanN）；不可与 标记 共存（:t* 不被允许），绝不可与 非成员 共存（:*）。
序列化规则：裸 lanN=不标记+PVID，lanN:u=不标记，lanN:t=标记。（lanN:t* 标记+PVID 不被允许）
