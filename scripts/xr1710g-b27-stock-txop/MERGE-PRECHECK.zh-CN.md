# B27 原厂调度合并前复核结论

本次按“仔细核实，无实质缺失后再合并”执行。复核对象为当前B27源码与原厂量产5.1.1.12提取模块。结论：**仍存在影响正确性的缺项，整体合并条件不成立。本次没有修改、合并或编译驱动，也没有访问路由器。** 这不是固件验收通过报告。

## 本次新增确认

### 1. 动态BA缺少原厂策略必需的PER输入

原厂 `UniEventAllStaUnsolicitHandler` 的0xd6b24读取统计记录+8的失败数，0xd6b28加载100，0xd6b2c做32位乘法，0xd6b30除以尝试数，0xd6b34保存PER。周边路径检查尝试数非零。公开SDK `chip/mcu/cmm_fw_uni_event.c:7460..7467`与此相符。

B27已有12字节的ALL_STA TX_STAT结构，包含 `attempts` 和 `failed`；但 `mt7996/mcu.c:1054..1055` 调 `mt7996_stock_event` 时第二项传0，`stock_policy.c` 的TX_STAT分支只保存attempts。故目前调度器不能按原厂PER>35/<15规则调整窗口。

这不是“固件不提供失败数”，而是B27主机处理尚未保留已有字段。需要补齐同一报告周期的失败数、空样本规则、read-clear时序与reset隔离。不能使用TX-free累计 `tx_failed` 直接替代：当前 `mac.c` 中该值包含重试信息，语义与原厂报告不能未经核实等同。

即使补齐PER，也还缺索引/窗口完整对应、BA会话状态、MLO映射与恢复。原厂DW7回调存在，不足以证明可以安全搬入当前驱动。

### 2. WTBL地址选择涉及共享状态

当前 `mt7996_mac_wtbl_lmac_addr` 会先写 `MT_WTBLON_TOP_WDUCR` 选择WCID组，再返回地址。airtime轮询、信号读取、固定GI都使用这一路径。动态BA若另起工作直接选择组并RMW，需要核对所有并发上下文以及FW是否修改同一DW。

`stock_work`持有mt76 mutex本身不能作为“所有WTBL访问都由同一锁保护”的证明。需要覆盖站点删除、重连、SER及轮询并发，避免读错组或用旧DW覆盖FW新字段。本次未新增未经同步核实的寄存器写入。

### 3. VOW差异不能靠乘二一项补齐

当前表的源码注释明确说明：减半是为了映射mac80211 airtime weight；默认weight256映射BK/BE/VI/VO索引3/3/2/1。原厂表配合2/2/1/0，BE时间片分别2560/4096微秒。

若仅换表，当前默认BE会变为5120微秒，而不是原厂4096微秒。因此表、索引、用户airtime weight行为必须作为整体核对。

当前命令还将WATF与ATF同时启用。量产 `vow_watf_is_enabled:0x2ffd24..0x2ffd34` 已确认读取adapter+0x130bb6c；原厂feature命令确实读取这个独立字段，而非跟随ATF。三band配置留空，加上整块分配清零，支持默认0，但还未完整排除初始化别名/宽写覆盖。

本轮扫描到的同偏移写入主要来自profile解析和运行时setter；该扫描不是完整指针分析，不能据此声称穷尽所有写入。保留这项限定，不默认打开厂商可选策略。

### 4. MCLI不是单一TXOP开关

默认多客户端TXOP与可选CW/WRR分别受不同条件控制。客户端方向分类、上一周期包长、分阶段整数取整、独立优先级票和退出恢复仍需实际实现并验证。当前peak TXOP不能作为MCLI已移植的替代。

这类规则至少16个合格客户端才触发，不能仅凭其缺失就把单客户端2.4GHz低速归因于MCLI。现有5GHz近远端策略也不构成2.4GHz修复证据。

### 5. RED/ACM与WM/WA仍有边界

RED初始化启用与当前关闭的差异真实存在，但原厂RED报告函数目前唯一重定位仍是.eh_frame；未找到有效事件接入。WA内部可能独立管理RED，不能虚构一个主机反馈入口。

ACM涉及实际token资源池，原厂16384回退值不能无条件套用当前WED/NPU。WM/WA构建和哈希也不同，原始文件代码区域标有加密位，现有材料不足以证明内部算法一致。完整原厂调度承诺不能由主机参数匹配替代。

## 合并判定

| 条件 | 结果 | 原因 |
| --- | --- | --- |
| 原厂主机规则基本可定位 | 部分满足 | 真实回调、门槛及默认表有证据，但全部状态转移尚未覆盖 |
| B27具备全部输入 | 不满足 | 调度器未保留TX_STAT失败数；MCLI统计及BA生命周期尚未补齐 |
| MCU ABI及硬件并发明确 | 不满足 | RED事件/ACM资源、WTBL并发及固定GI字段疑点未闭环 |
| 默认、退出、重连、SER行为一致 | 不满足 | VOW、BA和MCLI尚无完整实现与对应验证 |
| WM/WA内部调度一致 | 未证明 | 二进制不同且代码区域带加密标记 |
| 可以标记“全部原厂调度合并完成” | 否 | 存在以上实质缺项 |

本次保存的是核实结果，不是新调度补丁。B27已有147～149实现保持原状。未把未核实逻辑、旧原厂WM/WA或原厂专有源码合入驱动。源码基线和逐条证据见 `evidence/MERGE-PRECHECK.json`；此前完整证据见 `RETAIL-SCHEDULER-CONFIRMATION.zh-CN.md`。
